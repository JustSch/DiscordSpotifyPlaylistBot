# DiscordSpotifyPlaylistBot
### A Bot That Adds Songs From Youtube and Spotify Links On A Discord Server To A Spotify Playlist



## Instructions:
 The Spotipy library that this makes use of will require authorization on first use. If running in a headless environment make sure you that on your first use that you are runing this in a terminal that you can interact with. You will be required to copy the url that it gives into a browser. Then, paste the url given by your browser back into the terminal that runs this bot. Alternatively, you can copy the .cache file generated from a previous instance of this bot.

 #### Makes use an instance of [Youtube-operational-API](https://github.com/Benjamin-Loison/YouTube-operational-API) and [yt-dlp](https://github.com/yt-dlp/yt-dlp) to get song information. Make use of [spotipy](https://github.com/spotipy-dev/spotipy) to interact with Spotify
